Tier 1 Performance Review 012

Scope reviewed:
- src/irys/rlm/engine.py: _deep_read_document, _batch_deep_read, _investigate_lead
- src/irys/core/repository.py: _doc_cache, read()
- src/irys/matter/graph.py: DocumentInventoryStore.upsert(), is_ingested()

Findings

HIGH
- Same document cold-processed multiple times in one run. Leads investigated in parallel;
  each lead independently picks top files for deep-read. Inventory gate only skips
  'complete' docs; 'pending' docs are reprocessed until mark_ingested() runs.
  Fix applied: _reading_in_progress set on InvestigationState gates within-run dedup.

- Main OOM risk: unbounded _doc_cache in MatterRepository. Nothing evicts it.
  On broad searches, entire corpus text stays in RAM.
  Fix applied: capped at 200 entries with LRU eviction via OrderedDict.

MEDIUM
- Hot-path validation does full file read + sha256 on every rerun before first await.
  900 hot docs at 2MB avg = 1.8GB reread/run. mtime+size fast path would reduce this.
  Not fixed: correctness-first interim approach accepted.

- Cold-path gap detection rescans whole repository per cold doc. _file_cache unused.
  Not fixed: pre-existing, lower priority.

LOW
- upsert() fetches row, engine does second point lookup via is_ingested(). 3 SQL per hot doc.
  Not fixed: minor.

Gate: CLEAN (no unaddressed HIGH issues)
